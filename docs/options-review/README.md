## ✅ 重要提醒

### 所有Greeks和价格都记录**开仓时**的值

**为什么？**
- ✅ 复盘的目的是验证开仓决策是否正确
- ✅ 用开仓数据才能总结规律（如Delta 0.25的胜率）
- ✅ 平仓时的数据是结果，不是决策依据

**记录开仓时的：**
- Delta
- IV（隐含波动率）
- DTE（距到期天数）
- 股价

## 🎯 卖方黄金法则（提醒）

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| **Delta** | **0.20-0.30** | 20-30%行权概率 |
| **DTE** | **45-60天** | 低Gamma，安全 |
| **IV环境** | **IV Rank > 50%** | 高IV才值得卖 |
| **获利平仓** | **50%利润** | 不贪心 |
| **止损** | **2x权利金** | 严格止损 |

## 📈 统计功能

模板自动计算以下指标：

- **总交易次数** - 总共做了多少笔
- **盈利次数** - 赚钱的次数
- **亏损次数** - 亏钱的次数
- **胜率** - 盈利次数 ÷ 总交易次数
- **总收益** - 累计盈亏金额
- **平均收益** - 每笔平均赚多少
- **平均收益率** - 相对权利金的平均收益率

## 💡 使用技巧

### 1. 记录时机

**开仓后立即记录：**
```
✅ 开仓日期
✅ 标的、操作、行权价
✅ 到期日、DTE
✅ 股价(开仓)、Delta、IV
✅ 权利金
```

**平仓后补充：**
```
✅ 平仓日期
✅ 实际盈亏
✅ 盈亏%（自动计算）
```

### 2. 定期复盘

**每周复盘：**
- 查看本周交易
- 检查是否符合黄金法则
- 分析失败案例

**每月复盘：**
- 统计胜率和收益率
- 找出最成功的Delta/DTE组合
- 调整策略

### 3. 数据分析

**筛选数据：**
- 筛选Delta 0.20-0.30的交易，看胜率
- 筛选DTE 45-60天的交易，看收益率
- 筛选高IV环境（>80%）的交易

**透视表分析：**
- 按标的分组，看哪个股票最赚钱
- 按操作分组，卖Call vs 卖Put哪个好
- 按月份分组，看季节性规律

## 📋 Excel公式说明

### 盈亏%列（M列）

```excel
=L2/J2
```
- L2 = 实际盈亏
- J2 = 权利金
- 结果自动显示为百分比

### 统计公式

**总交易次数：**
```excel
=COUNTA(B2:B1000)
```
统计标的列（B列）有数据的行数

**盈利次数：**
```excel
=COUNTIF(L2:L1000,">0")
```
统计实际盈亏列（L列）>0的次数

**胜率：**
```excel
=B10/(B10+B11)
```
盈利次数 ÷ (盈利次数 + 亏损次数)

**总收益：**
```excel
=SUM(L2:L1000)
```
所有盈亏的总和

**平均收益率：**
```excel
=AVERAGE(M2:M1000)
```
所有盈亏%的平均值
