# 期权卖方速查卡

## 🎯 开仓标准（必须满足）

| 指标 | 标准值 | 检查 |
|------|--------|------|
| Delta | 0.20-0.30 | ☐ |
| DTE | 45-60天 | ☐ |
| IV Rank | >50% | ☐ |
| 股价位置 | 确认虚值OTM | ☐ |

---

## 📊 开仓检查清单

### 1️⃣ 选择标的
- ☐ 看好的股票（或愿意持有）
- ☐ IV Rank > 50%（高IV环境）
- ☐ 有一定流动性（日均成交量>100万）

### 2️⃣ 选择行权价
- ☐ Call：选择股价上方10-15%的行权价
- ☐ Put：选择股价下方10-15%的行权价
- ☐ Delta在 0.20-0.30 区间

### 3️⃣ 选择到期日
- ☐ 45-60天到期
- ☐ 避开财报日（除非专门做财报策略）

### 4️⃣ 确认权利金
- ☐ 权利金 > 账户的1%（值得做）
- ☐ 风险收益比合理

### 5️⃣ 风险管理
- ☐ 单笔风险 ≤ 账户2%
- ☐ 设置止损：2×权利金
- ☐ 设置获利目标：50%权利金

---

## 💰 平仓规则

### ✅ 获利平仓
```
达到50%利润 → 立即平仓
```
**例子**：
- 收$250权利金
- 当期权跌到$125时买回
- 净赚$125（50%收益率）

### ❌ 止损平仓
```
亏损达到2×权利金 → 立即平仓
```
**例子**：
- 收$250权利金
- 当亏损达到-$500时止损
- 限制损失不超过2倍

### ⏰ 时间平仓
```
距到期<21天 → 考虑滚动或平仓
```
**原因**：Gamma风险增加

### 📰 事件平仓
```
财报前 / 重大新闻前 → 评估是否平仓
```

---

## 🚨 紧急情况处理

### 股价快速接近行权价
```
1. 检查Delta变化
2. 如果Delta > 0.40 → 考虑平仓或滚动
3. 滚动：买回当前期权，卖出更远/更高的期权
```

### 突发利空/利好
```
1. 评估对股价的影响
2. 如果方向不利 → 提前止损
3. 不要抱侥幸心理
```

### IV暴涨
```
对卖方有利！
- IV涨 → 期权价格涨
- 但你已经锁定收入
- 考虑是否提前平仓获利
```

### IV暴跌（IV Crush）
```
对卖方有利！
- 常见于财报后
- 期权价格暴跌
- 提前平仓锁定利润
```

## ⚠️ 常见错误（避免）

### ❌ 不要做的事

| 错误 | 后果 |
|------|------|
| Delta > 0.40 | 太容易被行权 |
| DTE < 21天 | Gamma爆炸，风险失控 |
| 低IV时卖期权 | 权利金太少，不划算 |
| 不设止损 | 小亏变大亏 |
| 持有到期 | 最后一周风险太高 |
| 裸卖期权 | 无限风险 |
| 频繁调整 | 手续费吃掉利润 |

## 💡 进阶技巧

### 滚动策略（Rolling）
```
当期权接近行权价时：
1. 买回当前期权（可能小亏）
2. 卖出更远的期权（收更多权利金）
3. 延长时间，增加距离
```

### 组合策略
```
不要单独裸卖，风险太大
- Iron Condor - 限制风险
- Credit Spread - 定义最大损失
- Covered Call - 持股卖Call
```

### 选股技巧
```
卖Call：选择你认为会涨但不会暴涨的股票
卖Put：选择你愿意买入的股票（万一被行权）
```
