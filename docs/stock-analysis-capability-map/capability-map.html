主流程能力链路

入口 → 数据情报 → 分析决策 → 输出分发

1) 触发入口

  • CLI 批量分析 / 大盘复盘 / 回测
  • Web：问股、立即分析、设置与组合
  • Desktop：Electron 单机运行
  • Bot：Discord/Telegram/飞书等命令触发
  • API：FastAPI 编排触发
  • Schedule：本地定时 + GitHub Actions
→

2) 数据与情报层

  • 行情 fallback：Efinance/Akshare/Tushare/Pytdx/Baostock/Yfinance/Longbridge/Tickflow
  • 基本面聚合：fundamental_adapter
  • 新闻检索：SearXNG + Anspire Search
  • 情绪与风险：贪恐指数、社交舆情、资金流、行业排行
  • 市场侧面板：Druckenmiller conviction、US 流动性
→

3) 分析与决策层

  • 16 个策略 Skills（趋势、结构、情绪、价值、股息）
  • 20 个 Agent Tools（数据/分析/搜索/市场/回测）
  • 技术分析：MA/MACD/RSI/KDJ/布林带/量价/形态
  • 估值分析：PE/PB/PS 分位（A 股完整，美股 partial）
  • 多策略联合评分：加权综合 + 仓位建议
→

4) 报告与分发层

  • 个股报告 + 大盘复盘（Markdown）
  • 历史记录与对比、上下文快照
  • 13 通知渠道并行分发（失败隔离）
  • 回测结果沉淀（按策略/股票维度）
  • Web/桌面端可视化消费

能力分层地图

按“分析对象”而非“代码目录”组织

技术分析

趋势与形态信号
  • 趋势判断：均线排列、MACD、RSI、KDJ、布林带
  • 量能结构：量比、放量/缩量、量价背离
  • K线形态：锤头、十字、双底、突破等模式识别

情报与情绪分析

信息面与市场心理
  • 个股新闻与综合情报检索（公告/风险/预期）
  • 贪恐指数（A/HK/US）逆向信号
  • 社交舆情与催化线索补充

估值与长期视角

价值/复利/股息框架
  • PE/PB/PS 历史分位：A 股可用度最高
  • 价值投资、高质量复利、股息成长三类长期策略
  • 当前美股估值历史分位能力为 partial（以当前值为主）

市场与宏观侧写

大盘复盘专题能力
  • 指数面板：A 股/美股核心指数
  • 行业板块强弱与轮动观察
  • 美股流动性（VIX/MOVE/TNX/DXY/HYG）与 conviction 面板

策略编排能力

规则策略 + Agent 工具协同
  • 16 个策略可在问股场景自由切换
  • 多策略联合对 11 个策略 + 贪恐信号做统一评分
  • 支持新增 YAML 策略并自动在前端加载

运营与可交付能力

报告、通知、回测闭环
  • 报告沉淀与历史对比，支持复盘追踪
  • 通知分发失败隔离，单渠道异常不拖垮主流程
  • 回测与组合模块可支撑策略迭代
