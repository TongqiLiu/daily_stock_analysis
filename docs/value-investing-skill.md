# 问股价值投资：数据边界与使用方法

问股首页保留「💎 价值投资」。适合研究企业的长期现金创造能力、价格条件和论点是否改变。输入股票代码，并说明是研究新标的还是复核持仓；需要量化仓位时补充账户规模、现有持仓、集中度和流动性需求。

结果先区分业务质量、当前价格和账户适配，结论为「长期配置候选」「观察并补证据」「暂不纳入」。资料不足会明确列出缺口；没有多年财务时不宣称持续五年高 ROE，没有账户约束时不默认重仓。护城河三重检验、资本配置和证伪清单保留，但不再用任意加权分数推导满仓或固定长期收益。

## 工具口径

- `get_stock_info` 保留基本面分块的覆盖率、数据源链和错误，以及上游提供的 `as_of`。抓取时间不能替代财报报告期或公告发布日期，工具也不会创造上游缺失的时间。
- `get_valuation_percentile` 返回**自身历史位置**，`rating` 文案为「历史极低/历史偏低/历史中位/历史偏高/历史极高」，不代表内在价值。现有字段名保留；`history_start`、`history_end`、`history_coverage_years`、`samples` 表示实际覆盖。请求五年不保证取到五年。历史日期需有效、去重、按时间排序且处于指定窗口；最新观测非正或无效不会改用更早的正值。少于 30 个有效样本或最新历史观测超过 31 天不计算当前分位。美股只有当前倍数时保持 `partial`，禁止用模型记忆补历史；港股当前仍不支持此历史端点。
- `get_dcf_valuation` 沿用既有工具与字段，是 **FCF 代理的敏感性模型**。优先使用有日期的最近年度现金流，不把负现金流替换成按 PE 推导的利润。经营现金流与资本开支必须来自同一报告期。财报期、行情时间、现金、债务、股数或币种缺失时不生成每股价格；不同财务/交易币种也不会按 1:1 换算。银行、保险、REIT 和基金不适用此普通企业模型。
- DCF 的证券身份复用项目通用规范化：支持 `SH.600519` / `600519.SH`、`HK.00700`、`US.AAPL` / `AAPL.US` 等输入；美股股类转为 Yahoo 的连字符格式。不能确认或明确市场冲突时不猜测 ticker。
- DCF 的 `retrieved_at` 是检索时间，`financial_period_end` 是实际年报期，`quote_as_of` 是供应商行情时间。年报超过 550 天或行情超过 8 天时不视为当前估值输入。缓存复用原时间，不刷新成“最新”。info 中只有聚合 FCF 而没有可核验报告期时仅返回输入与缺口。
- FCF 非正导致 `unavailable` 时，已获取的 `total_cash`、`total_debt`、`shares_outstanding`、币种及财报期仍保留。供应商现金/债务快照的具体期间尚未核验会单独标注，不能把“期间未核验”写成“数值全部缺失”，也不能把模型不适用等同于企业无价值。
- 即使数据齐全，自动 DCF 也返回 `status=partial`、`valuation_signal=scenario_only`、`decision_eligible=false`。增长率只是当前营收增长代理（限制在 -15% 至 +15%），没有数据时用零增长**演示假设**；折现率和永续增长率也只是敏感性假设，不是当前市场参数或企业预测。供应商 FCF 尚未调节利息、净借款、股权激励、稀释和 ADR 口径，不能视为完整 FCFF/FCFE。原 `enterprise_value`、`equity_value`、`intrinsic_price` 保留兼容，但必须按 `model_basis` 理解为情景演示结果，不能独立生成买入结论。
- 每个 DCF 情景给出终值现值占比，以及 `(估值−现价)/估值` 的情景折价。它不同于 `(估值−现价)/现价` 的上涨空间。只有独立核验估值输入后，才能讨论已确认的安全边际。
- `get_stock_backtest_summary` 显示可归因的历史报告/交易执行表现。10 日等短期方向命中率、成本后收益只放在独立的“历史执行诊断”段，不参与三至五年护城河、内在价值、长期观点或价投结论置信度；高低表现均不能成为首段结论、结尾行动或观察理由。无技能归因时不给价投技能打分/排名，样本不足保留不足提示。即使尾部声明不能验证长期，也不得在正文中把该指标作为长期结论的依据。

## 验证与限制

离线回归覆盖负 FCF 不被盈利覆盖、跨币种/缺债务/未知日期阻止价格生成、同期间现金流、非有限数值、缓存时间、DCF 公式/安全边际分母、历史数据排序/窗口/冲突重复值和实际数据源链保留。服务仍依赖 yfinance / akshare 的可用性与数据质量；自动敏感性情景没有经过长期收益校准。直接可用意味着研究结论和数据缺口可复核，不意味着每只股票都能获得可执行买价。

现金流和折现率应匹配的模型边界参考 [NYU Stern 的估值方法说明](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/lectures/approach.html)。年度数据读取口径参考 [yfinance cashflow 文档](https://ranaroussi.github.io/yfinance/reference/api/yfinance.Ticker.get_cashflow.html)。本专题目前只有中文版本，没有对应英文文件；不改动首页级 README。
