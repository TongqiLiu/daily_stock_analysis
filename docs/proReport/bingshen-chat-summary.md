## 1. 一句话概括

这是一套以 **「量价关系」为核心、以「庄家手法可复用」为假设** 的 A 股波段交易框架：用放量/缩量、吞没、背离、圆弧底、双头等形态判断 **洗盘 vs 出货**，并给出 **N 字买法** 等具体入场/止损规则。当日重点警示 **光模块板块**（以中际旭创为锚）进入高位风险区。

## 2. 核心方法论

### 2.1 量价铁律（最底层）

| 场景 | 量价特征 | 解读 |
|------|----------|------|
| 健康上涨 | 上涨放量、下跌缩量 | 正常量价关系 |
| 健康回调 | 大阴线后很快被大阳线包住 | 多头仍占优 |
| 危险信号 | 高位放量大阴线 | 板块/个股进入谨慎区 |
| 危险信号 | 缩量涨（价升量缩） | 背离，不宜追 |
| 危险信号 | 量价背离叠加硬顶 | 多为诱多，骗进去杀 |
| 出货特征 | 放量跌 | 对照历史「前面作业」判断 |
| 洗盘特征 | 缩量跌 + 底部不破 | 等量能反包再考虑买 |
| 惜筹信号 | 长阴短柱（价跌量不大） | 庄家惜筹，非恐慌出货 |

### 2.2 高位见顶与二波条件（中际旭创 → 光模块）

**触发日逻辑**（以中际旭创为例）：

1. 出现 **高位放量大阴线** → 从该日起光模块「不好再玩」。
2. 从该日往后 **累计红绿量能** 粗算对比：后续上涨若是 **缩量涨** → 更危险。
3. 回踩后若要重新看多：需 **放量反包**（量价齐包）。
4. 个股仍可能创新高或走二波，但前提是 **量价齐包**；若量跟不上 → 大概率 **双头**。

### 2.3 N 字买法（可操作的入场模板）

**形态**：放量涨 → 缩量跌（N 字洗盘）。

**入场**：

- 在放量阳线 **实体 1/2 附近** 找买点（等结构细节）。
- **止损**：设在放量阳线 **底部**（约半根 K 线风险，~5%）。

**示例**：

- Day1：10 → 11 放量涨
- Day2：缩量回调
- 买点 ~10.5，止损 10

**注意**：需结合该股庄家历史洗盘深浅（「前面有作业抄」）；次新股筹码结构怪异需格外小心。

### 2.4 洗盘 vs 出货（决策树）

```
当前下跌中
├─ 缩量跌 + 底部未破 → 偏洗盘，等周一/后续量能反包
├─ 本应缩量却放量（如麦格米特当日）→ 不再是洗盘，偏出货图
├─ 放量跌 → 对照前面历史，多为出货
├─ 45° 直线下跌 → 阶梯式出货，非洗到底
└─ 横着跌 / 区间内三根大阳线后横盘 → 主力仍在区间内洗，非出货
```

**出货的典型手法**（冰封之谷自述）：

- 若主力要出货：会利用大阳线拉高，制造 **二波预期**，高位分批跑。
- 真出货后的砸盘：**非高位放量砸** = 弃庄。
- 横盘震荡 + 大阳线后不走横拉出货形态 → 当前不像出货。

**假弃庄**：凯格精机等 — 庄家故意让你以为弃庄。

### 2.5 形态与关键位

| 形态/概念 | 规则 |
|-----------|------|
| **圆弧底** | 底部不破则结构健康；跌破圆弧底 → 做头风险 |
| **双头/M 顶** | 必须等 **跌破颈线** 才确认 |
| **硬顶** | 连续几根顶在同一区域 → 多为诱多 |
| **多空线** | 取圆弧底最低点（如 76 元），主升浪回踩确认 **两次** 后升格为关键位 |
| **二次触底** | 二次触底 + 确认底部后再拉 — 「一招鲜」套路 |
| **阶梯式出货** | 不能一直 45° 直下，要横着跌才算洗盘到底 |

### 2.6 筹码结构（需专业软件）

- 结合 **筹码分布**：看筹码是否上移、是否形成新「顶格」。
- 次新股（如盛合晶微）筹码结构常怪异，急跌不意外。
- 天华新能等案例使用通达信类 **成本分布**（获利比例、90%/70% 筹码集中度）辅助判断。

### 2.7 交易哲学（非技术指标）

- **业绩无用论**（短线语境）：庄家先蹲好，业绩只是「告白」。
- **不追求吃满**：庄家吃三倍，你吃一倍即可。
- **呆米原则**：不动就不做；只做自己懂的票。
- **盈亏比优先**：上车位置与盈亏比要想清楚。
- **同一庄家手法可复用**：利扬、芯原、三环、聚合材料等「换汤不换药」。

## 4. 可提炼的检查清单（人工复盘用）

### 4.1 买入前（多头）

- [ ] 上涨是否 **放量**，回调是否 **缩量**？
- [ ] 回调是否 **未破前低/圆弧底/多空线**？
- [ ] 是否出现 **N 字** 或 **二次触底确认**？
- [ ] 买点是否在放量阳线 **1/2** 附近？止损是否在阳线底？
- [ ] 筹码结构是否上移？（有工具时）
- [ ] 盈亏比是否合理？

### 4.2 回避/减仓（空头或观望）

- [ ] 是否出现 **高位放量大阴线**？
- [ ] 是否 **缩量涨** 或 **量价背离**？
- [ ] 是否 **硬顶 + 诱多**？
- [ ] 洗盘日是否 **异常放量**（该缩不缩）？
- [ ] 是否 **放量跌** 且与历史出货图相似？
- [ ] 双头是否已 **跌破颈线**？（未破不急于判死）

1. **无系统课程**：被问及时，冰神表示「没有的哈哈哈」—— 规则来自经验，非完整教材。

## 6. 能否蒸馏为 Skill？— 评估

### 6.1 结论（TL;DR）

| 形态 | 可行性 | 说明 |
|------|--------|------|
| **分析型 Skill**（检查清单 + 结构化报告） | ✅ **推荐** | 与仓库 `five-dimension-stock-analysis`、longbridge-technical 等互补 |
| **富途/通达信指标 Skill** | ⚠️ **部分可行** | 量价规则可写公式；庄家/筹码部分难自动化 |
| **全自动交易信号 Skill** | ❌ **不推荐** | 误判成本高，原文本身强调「不是不能买，是要非常小心」 |

**总评**：值得蒸馏为 **「冰神量价分析」辅助 Skill**，定位为 **启发式技术面子框架**，而非独立全自动策略。

### 6.2 适合编码化的规则（高置信）

以下可用日线 OHLCV 近似实现：

1. **高位放量大阴线**：N 日新高附近 + 跌幅 > X% + 成交量 > MA(VOL,5)×K
2. **缩量涨/量价背离**：价创 N 日新高但 VOL < 前高日 VOL
3. **涨放量跌缩量**：近 M 日上涨日均量 > 下跌日均量 × 比例
4. **N 字买法**：识别放量阳线 → 缩量回调 → 回调低点 ∈ [阳线底, 阳线中位]
5. **双头颈线**：两高点接近 + 跌破中间颈线幅度 > 阈值
6. **阶梯式出货**：下跌斜率超阈值且缺少横盘段

可与现有 `.claude/skills/futu-indicator-writer` 联动：先由分析 Skill 输出条件，再生成富途副图信号。

### 6.3 难以编码的部分（低置信）

1. **「对照前面作业」**：需要该股历史形态模板匹配（ML 或人工标注库）。
2. **洗盘 vs 出货的最终判定**：同一「放量跌」在不同上下文结论相反。
3. **筹码顶格/成本分布**：数据源与雪球不一致时需额外接入。
4. **「硬顶」「诱多」**：缺少客观定义，宜保留为 LLM 读图定性，不宜硬编码。
5. **跨股「同一套路」**：利扬/芯原/三环类比 — 属于模式识别 + 经验，非单股指标能覆盖。

### 6.4 建议的 Skill 形态（若落地）

**名称（草案）**：`bingshen-volume-price-analysis`

**触发**：用户要求「冰神量价」「N 字买法」「洗盘还是出货」「光模块高位风险」等。

**输入**：股票代码 + 日线（优先复用 `data_provider/` / longbridge）+ 可选筹码截图。

**输出**（固定三段，对齐仓库 Skill 惯例）：

1. **量价诊断**：7 条铁律逐条打勾/打叉 + 置信度
2. **形态判定**：洗盘 / 出货 / 观望 + 关键位（多空线、颈线、N 字买点止损）
3. **行动建议**：买/等/减 + 风险点（非投资建议免责声明）

**依赖**：

- 数据：`longbridge-kline` 或现有 `data_provider` 日线
- 可选：`futu-indicator-writer` 生成副图公式
- 参考本文档 + 原 RTF 截图（`docs/proReport/冰神聊天.rtf`）

**不建议**：

- 写入 `main.py` 默认分析流水线（风格主观、与五维框架可能冲突）
- 作为无人工复核的自动下单依据
