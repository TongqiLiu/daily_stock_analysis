# 冰神量价规则与量化阈值

> 「执行层」阈值：从聊天案例反推的默认参数，非原作者明示数值；实盘应结合流动性、市值与板块调整。
> 标注 **原框架** = 聊天中明确表述；**执行层** = 为 skill 可执行性补充。

## §1 七条铁律 — 量化判定

### R1 上涨放量、下跌缩量（健康量价）**【原框架】**

**执行层默认（近 20 交易日）**：

- `up_avg_vol` = 收涨日成交量均值
- `down_avg_vol` = 收跌日成交量均值
- ✅：`up_avg_vol >= down_avg_vol * 1.10`
- ⚠️：比值 ∈ [0.95, 1.10)
- ❌：`up_avg_vol < down_avg_vol * 0.95`

### R2 大阴线后被大阳线包住 **【原框架】**

在最近 30 日内寻找：

- 大阴线：`pct_chg <= -3%` 且实体占振幅 ≥ 50%
- 包住：其后 3 日内出现阳线，且 `close >= 大阴线open` 且 `volume_ratio >= 1.0`

### R3 高位放量大阴线 **【原框架】**

锚点日定义（触发板块/个股谨慎）：

- 收盘价 ≥ 60 日最高价的 85%
- 收跌：`close < open`，且 `pct_chg <= -3%`
- 放量：`volume >= MA(volume,5) * 1.5`
- 收盘偏弱：`(close - low) / (high - low) <= 0.35`（收在当日下 1/3）

记录锚点日 `T0`；自 `T0` 起累计红绿量能仅作粗算参考。

### R4 缩量涨 / 量价背离 **【原框架】**

在最近 30 日内：

- 价格创 20 日新高（或 ≥ 前高 99%）
- 当日量 < 前一波高点日成交量的 85%
- 或：连续 3 日收涨但成交量逐日递减

### R5 回调缩量且底部未破 **【原框架】**

- 近 10 日存在下跌段，下跌日均量 < 前 10 日上涨段均量 * 0.85
- 最低价 ≥ 前一波明显低点（20 日内局部低点）* 0.98

### R6 长阴短柱（惜筹）**【原框架】**

- 单日跌幅 ≥ 4%
- 当日 `volume_ratio < 0.85`（相对 5 日均量）
- 且后续 3 日未创新低

### R7 二波量价齐包 **【原框架】**

在 R3 锚点日之后：

- 价格反弹突破锚点日前一高点
- 且反弹日 `volume >= 锚点日 volume * 0.9`
- 不满足 → 双头风险上升（仍须颈线跌破才确认）

## §2 洗盘 vs 出货决策树

```
START: 近端处于调整/下跌
│
├─ [P1] 存在 R3 高位放量大阴线？
│   └─ YES → 主判定倾向「高位风险」；二波需 R7
│
├─ [P2] 近 5 日下跌但 volume_ratio 均值 > 1.2？（该缩不缩）
│   └─ YES → 主判定倾向「出货分发」（麦格式）
│
├─ [P3] 近 10 日跌幅 > 15% 且下跌日占比 > 70%，横盘天数 < 3？
│   └─ YES → 「阶梯式出货」，非洗到底
│
├─ [P4] R5 满足（缩量跌 + 底未破）？
│   └─ YES → 倾向「洗盘蓄势」；等待量能反包
│
├─ [P5] 大阳线后横盘，未走「拉高二波出货」形态？
│   └─ YES → 倾向「洗盘蓄势」（天华式）
│
└─ DEFAULT → 「观望待确认」；拉 120 日历史对照
```

### 主力出货手法（定性 checklist）**【原框架】**

- 拉高制造二波预期后高位分批派发
- 非高位放量砸盘 ≈ 弃庄（真砸）
- 假弃庄：急跌吓人但结构未破（凯格精机类）→ 标「假弃庄观察」

## §3 N 字买法 **【原框架】**

**模板识别（执行层）**：

1. **B 日（放量阳）**：`volume_ratio >= 1.5` 且 `close > open`，涨幅 ≥ 3%
2. **回调段（1–8 日）**：至少 1 日收跌，回调段均量 < B 日量 * 0.75
3. **买点区间**：`[B.low, (B.open + B.close)/2]`
4. **止损**：`B.low * 0.995`
5. **盈亏比**：入场前估算至前高距离 vs 止损距离，< 2:1 则标「盈亏比不佳」

**过滤**：

- 次新股（上市 < 180 日）→ N 字信号降级为 ⚠️
- R3/R4 已触发 → 不主动给 N 字买点

## §4 形态规则

| 形态 | 确认条件 | 失效 |
|------|----------|------|
| 圆弧底 | 低点抬高 + 回撤不破前低 | 收盘跌破圆弧底低点 |
| 双头/M 顶 | 两顶接近（±3%）且 **收盘跌破颈线** | 未破颈线不确认 |
| 硬顶 | 3+ 次冲高未能放量突破前高（执行层） | 放量突破前高 |
| 多空线 | 圆弧底最低点；主升浪回踩确认 2 次 | 有效跌破 |
| 二次触底 | 两底接近 + 第二次放量企稳 | 跌破双底 |

## §5 筹码结构（近似）**【原框架 + 执行层】**

有 `ChipDistribution` 或近似 volume-profile 时：

- 获利比例极低 + 价格靠近 90% 筹码下沿 → 吸货/筑底观察
- 90% 集中度快速扩大 + 价格远离平均成本 → 结构怪异，降级
- 必须标注 `数据来源: approx_volume_profile`

## §6 板块锚定 **【原框架·案例】**

用户分析光模块/CoWoS/光芯片链时：

- 默认锚：`中际旭创`（300308.SZ）
- 锚定标的触发 R3 或 R4 → 板块内同级标的整体上调风险等级
- 板块结论写「板块锚警示」，不单票豁免

## §7 交易哲学（写入报告「纪律」段）**【原框架】**

- 呆米：无量价结构不出手
- 只吃一段：不追求吃满主升
- 盈亏比优先于胜率叙事
- 同庄手法可复用：对照历史形态比单看当日更重要
