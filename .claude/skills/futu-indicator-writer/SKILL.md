# Futu Indicator Writer

将用户的自然语言交易想法，转换成可在富途指标编辑器中直接粘贴/保存的指标脚本。

## 何时使用

当用户提到以下任意场景时，必须使用本 skill：

- “帮我写富途指标”
- “把这段策略翻译成富途公式”
- “我要主图/副图信号脚本”
- “给我可导入富途的指标代码”

即使用户没明确说“公式语言”，但只要目标是“富途里能跑”，就使用本 skill。

## 目标输出

输出必须包含三段，顺序固定：

1. `脚本代码`：可直接复制到富途指标编辑器
2. `参数说明`：每个参数的默认值与可调范围
3. `导入自检`：3-6 条快速检查点（防止无信号/未来函数/画图异常）

## 执行流程

### Step 0: 优先对齐“已验证样例风格”

如果用户提供了“富途已验证可用脚本”（例如 `.ftindex` 导出的公式段），优先复用该风格：

- 赋值/输出风格与样例一致：可混用 `DIF:EMA(...)`（输出线）与 `N1:=...`（中间变量）
- 每句以 `;` 结束
- 布尔运算使用 `AND / OR / NOT`
- 绘图风格与样例一致：可为 `DRAWTEXT(...)`、`STICKLINE(...)` 或两者混用
- 逻辑运算符与样例一致：支持 `AND/OR/NOT` 与 `&&/||`（优先跟随样例）

不要在未确认兼容性时擅自改写成另一种风格（例如把样例里的 `STICKLINE` 全改成 `DRAWTEXT`，或把 `&&` 强改为 `AND`）。

### Step 1: 把需求结构化

先将用户自然语言拆成以下字段：

- 指标类型：主图 / 副图 / 选股（若用户没说，默认副图）
- 触发条件：买入、卖出、预警
- 周期与参数：MA/EMA/RSI/MACD 等窗口
- 画图要求：箭头、文字、柱状、颜色
- 过滤条件：成交量、波动率、趋势过滤

缺失字段时，使用稳健默认值，不要阻塞用户。

### Step 2: 生成富途脚本

按 `references/futu_formula_cheatsheet.md` 里的写法生成。

强制要求：

- 变量名简洁、全大写（如 `MA5`, `BUY_SIG`）
- 不使用未来函数
- 每个信号条件都拆成中间变量，避免一行过长
- 画图表达与逻辑分离（先算信号，再 DRAW）
- 默认输出“副图/主图通用公式段”，避免依赖不确定函数
- 若用户提供样例，必须先做“样例风格匹配”：
  1. 识别赋值/输出语句风格（`:=` vs `:`）
  2. 识别绘图函数族（`DRAWTEXT` / `STICKLINE`）
  3. 识别颜色写法（`COLORRED` 等）
  4. 识别是否含参数变量（如 `S/P/M`）并保持同风格
  5. 识别是否使用中文变量名、注释块 `{...}`、`&&/||` 写法

### Step 3: 做一致性审查

提交前自查：

- 条件是否互斥/冲突
- 信号是否几乎永不触发（过严）
- 信号是否过于密集（过松）
- 参数是否全部可解释

### Step 4: 返回最终结果

严格按“脚本代码 -> 参数说明 -> 导入自检”输出。

## 默认参数策略（当用户未指定）

- 均线：`5/10/20`
- MACD：`12/26/9`
- RSI：`6/12/24`
- 成交量过滤：`VOL > MA(VOL, 5)`

## 输出风格约束

- 先给可运行版本，再给可选增强
- 不输出与富途无关的伪代码
- 不解释基础概念，除非用户追问
- 若存在兼容性分歧，先给“与用户样例同风格”的保守版本，再给增强版本
- 若用户给了多个样例（如 CC/CD/NX），优先输出“可同时兼容这些样例习惯”的版本，并注明你采用了哪种风格。
- 对于 ZBBL 类混合脚本，允许“输出线 `:` + 中间变量 `:=` + `STICKLINE/DRAWTEXT` 共存”，不要误判为不规范。

## 示例触发

用户说：

- “给我一个突破20日新高+放量的买点副图”
- “写个MACD金叉但只在MA20上方触发的主图信号”
- “把这段策略改成富途能用的脚本”

都应直接调用本 skill。
